تحديث بصمتي المهنية — إزالة التنبيهات وإضافة صورة الشعار

هذه حزمة تحديث للمستودع الحالي Basmati، وليست منصة جديدة.

1. فكّي ضغط الملف على الآيباد.
2. افتحي مستودع Basmati في GitHub، في الصفحة التي تظهر فيها app.js وindex.html.
3. اختاري Add file ثم Upload files.
4. ارفعي هذه الملفات الأربعة معًا إلى جذر المستودع بدل الملفات الموجودة:
   app.js
   database.js
   index.html
   style.css
5. اضغطي Commit changes.
6. انتظري اكتمال نشر Render. إذا لم يبدأ تلقائيًا اختاري Manual Deploy ثم Deploy latest commit.
7. حدّثي صفحة المنصة، ثم افتحي إعدادات النموذج، وأضيفي صورة الشعار واضغطي حفظ الإعدادات.

مهم:
- لا تستبدلي config.js؛ رابط مشروعك ومفتاحه الحاليان لا يحتاجان تعديلًا.
- لا يحتاج هذا التحديث أي SQL جديد أو تغيير في القاعدة.
- أبقي ملف qrcode.js والصورة professional-growth.webp بجانب index.html كما في مستودعك الحالي.
- إعدادات Render الحالية: Root Directory فارغة، Build Command هو echo ready، وPublish Directory نقطة واحدة .
- الملف index.html هنا يستخدم qrcode.js الموجود في جذر المستودع الحالي.

الشعار:
- يقبل PNG أو JPG أو WebP حتى 5 ميجابايت، وتُجهّز نسخة صغيرة منه تلقائيًا.
- تُعرض معاينة ثم يُحفظ عند الضغط على حفظ الإعدادات.
- يظهر في ديباجة التقرير وPDF ويُرفق بالتقييمات الجديدة.
- يُحفظ اختيار الشعار على المتصفح المستخدم، ولا يغيّر شعار الأجهزة الأخرى تلقائيًا.
- يوجد زر لإعادة الشعار الافتراضي.

التنبيهات:
- أزيلت رسائل نجاح الحفظ والتصدير والمسودة والعبارات التي تذكر Supabase في الواجهة.
- بقيت رسائل الحقول الناقصة وتعذّر الإرسال بصياغة بسيطة، حتى لا يُفهم أن التقييم أُرسل وهو لم يُرسل.

تم تجهيز هذه الملفات من نسخة المستودع الحالية، وفحص الكود ورفع الشعار والتحقق من الملفات غير المدعومة.
لم يتم رفع التعديل إلى GitHub من هذه المحادثة لأن الصلاحية المتاحة للربط قراءة فقط.
